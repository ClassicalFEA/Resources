# INP2DAT
Convert Abaqus/CalculiX INP file (nodes and elements) to a Nastran/MYSTRAN DAT/BDF deck.
Primarily for use with FlexFEA and solid elements (4-node tet and 10-node tet).
This a legacy converter with only basic functionality and is no longer supported.
DeckSwap is the preferred converter, which is significantly more advanced.
