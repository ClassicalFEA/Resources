ComLab (Computational Mechanics Lab or CML), sometimes referred to as "Nast-Core", is a finite element solver derived from Nastran-95 and subsequently improved by Harry Schaeffer.
It is stored at https://github.com/ClassicalFEA/ComLab

It is no longer being developed and no longer officially supported. Source code is not available.

The package contains the compiled files, run batch file, install instructions (if "installed" via environment variables), manual, improvements compared to Nastran-95, and agreements.
